# 减重训练风险闭环 · 承诺与争议处置后端

针对“急速暴瘦 / 不瘦退款”营销引发的退营与健康争议，本服务把广告素材、销售话术、
合同版本、付款计划、阶段测量、请假退营、投诉证据与退款协议统一冻结为**只追加事件**，
并按签约时承诺计算退款候选，支撑调解、退款批准、监管答复的分权处置与月度核对。

## 设计要点

- **冻结来源与有效期**：每份材料带 `source / fingerprint / valid_from / valid_until`。
  合同签署时快照当时生效的承诺（`adopted_promise`），承诺之后改版不影响已签合同。
- **原始记录不可改写**：阶段测量、安全事件一旦冻结只能追加补充说明；销售/教练本人
  离职后其历史记录继续有效，但不能再操作。
- **只追加哈希链日志**（`src/journal.py`）：每行带内容指纹与 `prev_digest`，原地改写、
  删除、插入在重放时立即被发现；`event_id` 完整重传只记一次，内容不同即拒绝。
- **标识冲突即锁案**：同一支付/证据回执标识相同而金额、文件指纹或提供方变化，立即
  锁定相关案件；锁案期间处置命令一律拒绝，但证据仍可继续保全，保全期限不丢失。
- **可计算退款候选**（`src/domain.py`）：
  - 健康原因：关联安全事件全额退已付款；否则按已付扣除已交付课时；
  - 服务未履行：到期未交付课时按合同单价退还；“不瘦退款”经冻结测量确认未达标时
    按承诺补足；
  - 普通反悔：冷静期内退已付款扣已消费课时与管理费，超期候选为 0（迟到投诉照常受理，
    只是金额规则不同）。
- **已付款和解只能冲正/补付**：不删除原出账事实；多付追加红冲、少付追加补付。
- **结算不能关闭监管事实**：监管调查未结时案件不能关闭；和解协议以删除记录为条件
  直接拒绝。
- **跨门店续营继承**：消费者签新门店合同时，名下未结争议自动并入新门店待办。
- **分权**：调解（争议专员）、退款批准（批准人）、监管答复（监管人）三角色互不重叠，
  且同一自然人不得跨角色办理；专员只能调取双方可见材料。
- **并发控制**：案件处置命令带期望版本号；并发和解只有一个能提交，另一个收到版本
  冲突，重试时撞上“一案只能一次和解”。
- **故障恢复**：重启重放日志即还原全部状态；分期出账按回执标识幂等，恢复后不重复
  付款、不丢失证据保全期限。

## 目录

- `contracts/domain.schema.json`：事件类型、聚合类型与信封契约。
- `src/journal.py`：只追加 JSONL 哈希链、内容/文件指纹、幂等重传、篡改检测。
- `src/freeze.py`：角色与分权定义。
- `src/domain.py`：三类退款原因的纯计算规则（含每笔计算明细行与依据）。
- `src/services.py`：事件溯源应用服务（承诺、合同、付款、测量、安全事件、争议、
  证据、调解、候选、批准、出账、冲正、补付、调查、结案、跨店继承、锁案）。
- `src/readmodel.py`：消费者视图、门店待办、月度核对。
- `src/envelope.py` / `src/cli.py`：信封基础校验与命令入口。
- `scripts/seed_demo.py`：生成本地演示日志。
- `tests/`：退款规则、四类规定场景（销售离职 / 分期退款 / 迟到投诉 / 并发和解）与
  治理不变量测试。

## 本地运行

```bash
# 生成演示日志（19 条冻结事件）
python3 -m scripts.seed_demo data/demo-journal.jsonl

# 哈希链完整性校验
python3 -m src.cli verify data/demo-journal.jsonl

# 消费者视图：采用的合同、每笔退款计算与结算调整
python3 -m src.cli consumer data/demo-journal.jsonl CONSUMER-1

# 门店待办（只含本店涉案事项）
python3 -m src.cli todo data/demo-journal.jsonl STORE-1

# 月度核对：承诺兑现、退款差额、未结调查、证据保全期限（对平退出码 0，否则 3）
python3 -m src.cli reconcile data/demo-journal.jsonl 2026-09

# 兼容原有单事件信封校验
python3 -m src.cli data/sample.json
```

运行测试与编译检查：

```bash
python3 -m unittest discover -s tests
python3 -m compileall -q src tests scripts
```

只使用 Python 标准库，无需数据库或外部服务；演示中门店/消费者标识均为测试数据。
